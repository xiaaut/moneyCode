- 财报缓存当前仅覆盖被访问过的股票（600887/600298/002507/603288 等有 health_score，其余「待体检」）。

### 实现
- `models/rebalance.py` + `migrate_rebalance.py`：rebalance_plans 表（含 account_tag、action_type、trigger_condition、status 等 14 字段）。
- `services/rebalance_service.py`：
  - `get_dashboard()`：聚合 positions + watchlist + kline（5 年分位/MA20/MA250/乖离）+ financial（finalize 重算健康分/雷达）+ stocks.roe + strategy_config 目标价，生成 4 类信号（BUY_ZONE/PROFIT_ZONE/RISK_ZONE/REBALANCE_ZONE），输出 summary（集中度/优质占比/信号数/已到价工单）+ signals + plans。
  - 工单 CRUD + `_refresh_triggered_status`（PENDING 工单到价自动 TRIGGERED）。
- 路由 `rebalance.py`：GET dashboard + POST/PUT/DELETE plans + POST done。
- 前端 `Rebalance.vue`（浅色冰川蓝）：总览顶栏（集中度堆叠条 + 仪表卡）+ 筛选胶囊 + 信号卡片（价格水位尺：渐变轨道 + 现价●/成本◆圆点，标签外置）+ 底部双栏（工单表 + 补仓沙盘模拟器）。
- App.vue 挂载 `activeMenu === 'rebalance'` → Rebalance。

### 关键设计
- **价格水位尺防重叠**：文字外置（现价标签在轨道上方 22px、成本标签在下方 22px，绝对定位错开），轨道内只有 12px 渐变条 + 圆点，永不重叠/裁切。
- **补仓摊薄公式**：新成本 = (原成本×原股数 + 成交价×股数 + 佣金) / 新股数；佣金按万一免五（`price×qty×0.0001`）。回本涨幅 = (成本-现价)/现价。

### 实现
- `services/onboarding.py`：`auto_onboard_stock(code)`（Step1 无日线则拉 5 年前复权日线，Step2 A 股无财报则拉三表+张氏排雷落库）、`ensure_kline`/`ensure_financial`/`_prewarm_financial_one`/`_has_kline`/`_has_financial`。
- `POST /api/financials/batch-prewarm`：扫持仓+自选，过滤 ETF（`is_fund_ticker`），对缺财报 A 股依次拉三表落库（每只 0.25s 限流），`force=` 全量重算。
- 挂载点：`upsert_position`（POST /portfolio/positions）、`add_watchlist_item`（POST /watchlist/items）保存成功后 `asyncio.create_task(onboarding.auto_onboard_stock(code))`；`daily_sync._step_kline_incremental` 末尾 `_self_heal_financial()` 补齐未体检 A 股财报。
- `GET /api/kline/drawer/{code}?period=3m|6m|1y|3y|5y`（kline_sync.get_drawer_kline）：完整序列算 MA20/60/250 再按 period 截取（保证窗口左端 MA250 连续）；返回 position_info + rebalance_plans + financial_summary。
- 前端 `FundFlowDrawer.vue` 升级：加 K 线透视舱（信息栏含健康分胶囊跳分析报告 + 「去调仓沙盘」按钮 + 收盘价折线面积 + MA20/60/250 + 持仓成本虚线胶囊 + 目标线 + 红绿成交量柱 + 周期切换 + 十字准星悬浮）。`Rebalance.vue` 股票名称点击唤起抽屉；App.vue 加 `provide('openRebalance')`。

### 关键 bug 修复
- **`session.scalars(select(A, B))` 对多列 select 只返回第一列标量**，导致 rebalance_service 把 watchlist 当字符串列表、`w[0]` 取到字符（产生 code='0'/'6' 脏数据）。改为 `session.execute(select(A, B))` 返回 Row 列表。
- **库内 derived_metrics 的 driver_type 是旧值**（finalize 不重算 derived_metrics），rebalance/kline 读库显示旧驱动类型。将 `finalize` 改为 `analyze`（重算含 driver_type 的全部衍生指标）。
