# 2026-11-10 工作日志

## 数据底座最后一块：批量同步持仓/自选 5 年日线 + 挂入收盘流水线

### 同花顺批量历史日线接口（实测确认）
- `GET /api/a-share/prices/historical-batch`：`thscodes`（逗号分隔，**最多 10 个**）、`interval`（1d/1w/1mo）、`start`/`end`（毫秒时间戳，跨度 ≤10 年）、`adjust`（`forward` 前复权/`none`/`backward`，默认 forward）。
- 响应 `data.item[]`：`thscode` + `item[]`，每条 K 线字段 `date_ms/open_price/high_price/low_price/close_price/volume/turnover`（与 fund-market/historical 一致）。

### 实现
- `ths_client`：新增 `chunk_symbols(codes, size=10)` 静态切片 + `get_historical_batch(codes, start_ms, end_ms, interval, adjust)`（内部按 10 只切片循环调用，单 chunk 失败仅 warning 继续）。
- `kline_sync`：
  - `sync_etf_klines` 重构为 `sync_etf_klines_range(code, start_ms, end_ms)`（抽时间窗口）+ 兼容旧签名。
  - 新增 `sync_stock_klines(codes, start_ms, end_ms)`（A 股批量，adjust=forward）。
  - 新增 `_portfolio_codes()`（读 Position.code + WatchlistItem.stock_code，去重后按 `is_fund_ticker` 分流 ETF/A 股）。
  - 新增 `sync_portfolio_klines(years=5)`（全量）与 `sync_portfolio_incremental(lookback_days=15)`（增量，供收盘流水线用）。
- 路由：`POST /api/kline/sync-portfolio`（`years=` 默认 5）。
- `daily_sync`：STEPS 扩为 5 步（positions 15 / market 33 / fundflow 28 / lhb 19 / kline 5 = 100），`run_daily_sync` 末尾加 `_run_step(5, _step_kline_incremental)`，`_summary_for`/`_run_step` 加 index==5 处理。
- 前端 `GridTrading.vue`：回测抽屉「标的代码」由 disabled input 改为 `el-select`（filterable + allow-create + default-first-option），`portfolioOptions` 从 props.portfolio 提取 code+name，支持下拉选持仓或直接输入任意 6 位代码；`openBacktest` 允许空 code 打开抽屉，`runBacktest` 加 6 位代码校验。

### 关键避坑（重要）
- **asyncpg 参数上限 32767**：`UPSERT_BATCH=5000` 时单批 5000 行 × 10 字段 = 50000 参数直接报 `InterfaceError: the number of query arguments cannot exceed 32767`。这是 Parquet 全量同步的**原有隐患**（之前从未跑全量未暴露）。改为 `UPSERT_BATCH=2500`（2500×10=25000 参数）。
