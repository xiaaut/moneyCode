  - 成交打卡后立即 POST 单对象 upsert，失败回滚本地 trades
  - /api/quote 增加 symbol 参数；/api/grid 改用 symbol + 字符串 id + trades 数组结构
  - App.vue 侧边栏统一加 Element Plus 图标，并在进入网格页时重载持仓供导入
