### 同花顺 API 关键字段（实测确认，勿凭文档猜）
- 行情快照 `/api/a-share/prices/snapshot`（thscodes）：last_price / price_change_ratio_pct / volume / turnover（**无 name、无 PE/PB**）。
- 估值快照 `/api/a-share/valuations/snapshot`（thscodes）：name / pe_ttm / pe_mrq / pb_mrq / ps_ttm / pcf_ttm（**无市值**）。
- 财务指标 `/api/a-share/financials/indicators`（thscode + report=yyyy-n，单只）：abilities[] 内 index_id 实测带 `calculate_`/`parent_holder_` 前缀——营收同比=`calculate_operating_income_yoy_growth_ratio`、净利同比=`calculate_parent_holder_net_profit_yoy_growth_ratio`、ROE=`index_weighted_avg_roe`、毛利率=`sale_gross_margin`（**与文档示例字段名不一致，需包含匹配**）。
- 利润表 `/api/a-share/financials/income-statements`（period=quarterly 拿最新报告期累计 basic_eps）。
- 基金快照 `/api/fund/market/snapshot`（thscode）：ETF/LOF，last_price 等（**无 name、无估值**）。
- 认证：Header `X-api-key`。信封 `{code, message, data}`，code=0 成功。

## 修复：收盘更新「上次更新时间」重启丢失

- 根因：`daily_state.last_completed_at` 是后端进程内存态，`--reload` 服务在改代码时重启即清空。
- 修复：新建 `system_meta` 单例表（id=1，`last_daily_sync_at`），`migrate_system_meta.py` 建表；`run_daily_sync` 完成时 `_persist_last_completed()` 写库。
- `GET /api/system/daily-sync/progress` 三级兜底返回 `last_completed_at`：内存 → system_meta → stocks 表 `max(updated_at)`。
- 实测：重启后 progress 返回 `last_completed_at=2026-11-08T17:09:17`（stocks 兜底），前端按钮下方恢复显示。

## 第三阶段：K 线 Parquet 底座 + 网格历史回测

### 同花顺 Parquet/日线关键字段（实测确认）
- market-dumps 实际端点是 `/api/dump/market-dumps/{daily-k,daily-k-10d}/download-url`（不是用户描述的 `/api/a-share/market-dumps/*`），返回 `data.presigned_url`（S3 预签名链接，5 分钟有效），需二次下载 Parquet。
- 日 K Parquet schema：`thscode, currency, interval(1d), adjusted(none), date_ms(毫秒,Asia/Shanghai), open/high/low/close_price, volume(股), turnover(成交额)`，主键 (thscode, date_ms)，**未复权**、无 pre_close/turnover_ratio/qfq_close。
- fund-market/historical：单只 ETF 前复权日线，窗口最长 5 年，字段 date_ms/open/high/low/close_price(前复权)/volume/turnover。

### 实现
- `migrate_kline.py` + `app/models/kline.py`：stock_kline_daily（code+trade_date 联合主键 + trade_date 索引）。
- `app/services/kline_sync.py`：pyarrow `iter_batches(batch_size=50000)` 流式分块 + 每批 5000 行 pg_insert ON CONFLICT 落库；historical/incremental 走 market-dumps，ETF 走 fund-market/historical。`qfq_close` 未复权暂用 close、adjust_factor=1.0。
- `app/services/grid_backtest.py`：防未来函数逐日撮合（low 判定买入线、high 判定卖出线），等比网格（base_price 上下各 max_grids 档 step_pct），绩效指标（总收益/基准/超额/CAGR/最大回撤/套利次数/落袋利润），对比买入持有基准。
- 前端 GridTrading.vue：策略参数卡右上角「📊 历史回测验证」按钮 + el-drawer（表单 + 结果卡片 + SVG 净值对比 + 交易流水表）。

### 实测
- 510300 ETF 日线落库 1209 行（2021-11-11 ~ 2026-11-06，5 年）。
- 510300 近 2 年回测：网格 11.77% vs 基准 2.98%，超额 8.79%，年化 5.78%，最大回撤 10.43%（基准 20.11%），套利 11 次，落袋 11771 元。

### 关键避坑
- market-dumps 是 `/api/dump/...` 不是 `/api/a-share/...`，且先拿 presigned_url 再下载 Parquet。
- Parquet 未复权（adjusted=none），qfq_close/复权因子需另从 adjustment-factors dump 推导；ETF 用 fund-market/historical 直接拿前复权。
- pyarrow 26 在 Python 3.13 arm64 有 wheel，安装无碍。
