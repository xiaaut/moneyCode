## 技术债与风险

| 风险 | 影响 | 建议 |
| --- | --- | --- |
| `/api/*` 只在 `vite dev` / `vite preview` 生效 | `dist` 放静态服务器后所有读写 404 | 抽成独立 Node 服务或部署时保留中间件层 |
| `vite.config.ts` 已 1995 行 | 抓取、缓存、路由、构建配置耦合，改动风险高 | 拆为 `server/` 目录：上游抓取、缓存、路由分层 |
| 零测试、无 lint | 回归全靠手点，重构没有安全网 | 先把 `holdingsImport`、`gridCalculator` 的断言固化为 vitest |
| 全 JS SFC | `vue-tsc` 检查不到组件逻辑 | 新增代码逐步改 `lang="ts"`，至少覆盖 utils |
| Element Plus 全量引入 | bundle 1.06 MB，首屏偏重 | 按需引入或拆包 |
| `data/` 含真实持仓 | 泄露成本与仓位 | 保持私有仓库，禁止改公开 |
